# 理想好友 · 双人版

两人各答八道题，生成匹配度和闺蜜相处说明书。2026-11-17 已按用户要求移除头像选择与贴贴拍立得。

## 使用

- 同机：填写两个昵称，轮流作答。
- 异地：各自作答后交换 F2 结果码，粘贴合并；无实时房间与自动同步。
- 匹配度：相同选项题数 ÷ 8 × 100，四舍五入为整数，表示答题相似度。
- 说明书：合拍之处、容易误会之处、照顾彼此的小抄和相处约定。
- 误会章节：每张卡固定展示双方选择、一句可能的误会和一句建议；只列不同选项，全同答案显示没有明显选项差异。页面与长图一致。
- 保存：生成完整 PNG 长图。浏览器可下载或长按；小红书内使用公开的保存相册 API，失败时明确提示。

## 数据与兼容

进度优先写入支持版本的原生缓存，否则尝试 localStorage；昵称、答案仅在本机保存。旧记录中的头像字段在读取后移除，答案与分数保留。F2 码未变更，旧码兼容；码中昵称与选项可被解码，不宜公开分享。

独立版本未覆盖原 bxc-friendship 或线上版本；原源码在执行环境不可见，此版本基于已核对的原八道题、选项、四类期待及原图标重建，不含原白小纯动画及单人深度解读。
