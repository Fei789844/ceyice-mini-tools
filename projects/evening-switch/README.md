# 下班切换键

2026-11-22 制作。答六道题，从走一小段、记一笔、换盏灯和找人聊两句中挑一个喜欢的过渡动作。并列同时显示，可以返回修改或重测。

[网页体验](https://fei789844.github.io/tools/evening-switch/)

## 文件

- `dist/` 是完整静态网页。打开 `dist/index.html` 即可体验。
- `presentation/` 是原创图标和 3:4 封面。
- `release/tool.zip` 是静态归档包，入口位于 ZIP 根目录。

## 状态和验证

版本 1.0.0。尚未提交小红书审核，无 AppID。通过 4096 种计分组合检查及 Chrome 320px 手机尺寸的并列、改答和重测检查。平台模拟器、真机和当前上传口令待验证。答题仅在页面内临时运行，无需登录、联网或授权。
